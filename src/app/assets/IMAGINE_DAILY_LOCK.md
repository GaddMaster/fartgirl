# Imagine daily lock

You did **not** have enough before. The year JSON had story consistency. Imagine needs **visual** consistency, which is a different machine.

You have it now if you follow this recipe and do not improvise the lock text.

## Recipe (every single page)

1. Attach **Lena model sheet** as the reference image whenever the tool allows it.
2. Paste **MASTER LOCK** first. Same words, every day, all year.
3. Paste one **STATE LINE**.
4. Paste that post’s scene from the JSON (`image_prompt` / `scene_short`).
5. Paste **NEGATIVE**.
6. Generate **one portrait comic page**. If her face, hair, or suit changes, throw it away and rerun. Do not “fix in copy.”

## MASTER LOCK (copy exactly)

```
PROJECT CHLORIS — OFFICIAL MODEL LOCK. Use this exact character on every page.

STYLE: One printed comic BOOK PAGE, not a poster, not a cover, not a sticker. Thick black ink, visible gutters between panels, limited palette, grain, rain. Look like Invincible / Ultimate Spider-Man / Saga interiors. Portrait page.

LENA COLE / FART GIRL (same person every image):
- Age 20. Warm olive skin. Oval face. Straight dark brows. Slightly tired brown eyes. Small straight nose. Closed or tight mouth. Faint nick scar cutting the LEFT eyebrow. Dark brown almost-black hair in a MESSY LOW BUN, a few escaped strands. Small silver hoop earrings in civilian state.
- Body: athletic waitress, real proportions, not pin-up, not bodybuilder.
- CIVILIAN: stained black crew tee, faded olive apron reading THE DRIP in cracked white letters, dark jeans, scuffed black sneakers. No mask.
- HERO: simple dark-green eye MASK covering ONLY the eyes (no horns, no ears, no visor). Matte emerald bodysuit #0B6B3A with forest-green panels #0E3D24 on ribs, forearms, shins. Thin luminous mint seam-lines #3DFF88 like gas veins. Fingerless gloves. Low practical boots. NO cape. NO heels. NO cleavage window.
- Continuity mark: a faint luminous seam at the hollow of the throat, almost invisible as civilian, glowing as hero.

GAS: luminous emerald mist / shock-rings / vapor wake. Color #3DFF88 against dark scenes. Looks like toxic mist or chlorophyll lightning. NEVER brown. NEVER toilet. NEVER bodily function.

FART BOY (only if the scene names him): ~21, messy brown hair, orange-amber eye mask #E85D04 only, worn emerald suit, gold/yellow belt, orange gloves and boots, quiet face, slightly taller. Torn short cape only from behind on rooftops. Leaves inside a dense green cloud.

DO NOT: chibi, children's book, anime-only, photoreal live action, pin-up pose, extra logos, extra heroes, change hair color, give her a cape, put the mask on over the apron unless the prompt is a transformation beat, add a second different-looking Fart Girl.

PAGE RULE: follow the requested panel count. Each panel is another angle or beat of the SAME scene. Last panel should read as a cliff.
```

## STATE LINES (pick one)

Civilian: `STATE: Lena Cole civilian only. No mask. Apron on. Tired beautiful.`

Hero: `STATE: Fart Girl hero only. Mask on. Emerald suit. Same face as the model sheet.`

Transforming: `STATE: Transformation beat. Show civilian clothes fading into the emerald suit like smoke pulling into skin. Mask forms LAST.`

Both: `STATE: Split or multi-panel may show both states, but it is the SAME woman, same bun, same scar.`

## NEGATIVE

```
children's book, chibi, cute mascot, anime waifu, photoreal, 3D render, pin-up, sexy pose, cape on Fart Girl, high heels, cleavage cutout, brown fart cloud, toilet humor, extra characters not named, different hair color, blonde, red hair, changing her face, clean corporate superhero, Marvel style chrome, watermark, poster layout with no gutters
```

## Three anchors (if only three things survive, keep these)

1. Messy low bun
2. Nick scar through the **left** eyebrow
3. Dark-green mask that covers **eyes only**

## What still drifts (honest)

Imagine will still wander. No text prompt holds a face for 1,095 pages by itself. The model sheet is the real lock. If your app can send a reference image, always send the Lena sheet. If it cannot, keep the master lock byte-identical and reroll anything that breaks bun / scar / mask / suit color.
